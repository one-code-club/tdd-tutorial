# アプリ概要
このアプリは、子どもがBlocklyのブロックコーディングを活用して、TDDを体験するためのアプリです。画面中央にはBlocklyのブロックメニューと作業エリアがあり、そこにブロックの配置をし、実行すると裏でJavaScriptもしくはPythonが実行されるという仕組みです。

# システム概要
- next.jsの最新版, TypeScript, Tailwind CSS, ShadCNを利用したウェブアプリ
- Google Blocklyを活用したコーディング作業スペースと実行スペース

# インタフェース
- ログイン画面
  - 自分のニックネームを入力する
  - セッションにニックネームとIPアドレス、デバイスIDが記録される。次回以降はこれがマッチしたらセッションデータを取得する。
- ワークスペース画面
  - Headerにアプリ名、ニックネーム、ログアウトボタンを配置
   - 左サイドにBlocklyのブロックリストを表示する
     - Scratchと同じブロックを同じカテゴリに分けて表示してください
     - ユーザーはここからブロックを編集スペースにドラッグアンドドロップしてコーディングを行います。
- 実行スペース
  - 実行ボタンをクリックすると、書いたブロックコードがJavaScriptあるいはPythonに変換され、プログラムを実行する
  - ターミナルのようなコンソール画面で実行状況が表示される
= アプリスペース
  - GUIエリアで、既定の画像を表示し、そこでプログラムへのデータ入力と出力を受け取るようにする
  - アプリスペースはプログラムのmain関数に対してインプット値を指定するとともに、プログラムのアウトプットを受け取って、既定のアニメ動作をする
  - このスペースは最後に実装する

# 実装フェーズ
- まずはログイン画面とヘッダを実装し、空のワークスペース、空のアプリスペースを配置する
- 次にScratchクローンを生成する。Scratchと同じカテゴリとブロックを用意し、それを編集スペースにドラッグアンドドロップすることで、裏でスクリプト言語が生成される仕組みにする
- Scratchクローンができたら次のテストを行う
  - ブロックで次のコードを書く
  ```javascript
  x = 100;
  result = false;
  if (x >= 100) {
    result = true;
  }
  console.log(result);
  }
  ```
  - コンソールにはtrueが表示される。
  - ブロックの配列から実行までをやって、きちんとtrueが表示されるようになるまで修正とテストを繰り返してください。
